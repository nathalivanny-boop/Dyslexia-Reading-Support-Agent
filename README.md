# Dyslexia Reading Support Agent

## Project Overview
This project was developed for the Knowledge Based System assignment.

The system assists users with dyslexia by:
- Simplifying reading passages
- Explaining difficult vocabulary
- Extracting key points
- Generating comprehension questions

## Technologies Used
- Flowise AI
- Google Gemini 2.5 Flash
- LLM Chain
- Chat Prompt Template
